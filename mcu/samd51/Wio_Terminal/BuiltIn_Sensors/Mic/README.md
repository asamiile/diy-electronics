# Wio Terminal Microphone Threshold

[English](README.md) | [Japanese](README.ja.md)

## Overview

Reads `WIO_MIC` and attempts to display `TOO LOUD!` when the raw reading exceeds 500, holding it for two seconds. The code also pushes a sprite buffer; verify the actual screen behavior and adjust any future threshold changes for the environment. The reading is not calibrated sound pressure.

## Development

### Hardware Development

#### Hardware and dependencies

Wio Terminal and a data-capable USB-C cable; this example uses onboard hardware and needs no external sensor wiring.

Dependencies: `TFT_eSPI`.
