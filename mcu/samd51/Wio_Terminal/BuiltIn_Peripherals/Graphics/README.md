# Wio Terminal Graphics

[English](README.md) | [Japanese](README.ja.md)

## Overview

Demonstrates full-screen fills, a pixel, horizontal/vertical lines, rectangles, a circle, an ellipse, a triangle, a rounded rectangle, a character, and `Hello world!`. The drawing runs once in setup at rotation 3. Reset to replay the navy/gray/orange color sequence and check the final drawing.

## Development

### Hardware Development

#### Hardware and dependencies

Wio Terminal and a data-capable USB-C cable; this example uses onboard hardware and needs no external sensor wiring.

Dependencies: `TFT_eSPI`.
