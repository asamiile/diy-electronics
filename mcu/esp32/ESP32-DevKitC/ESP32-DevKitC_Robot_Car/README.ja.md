# ESP32-DevKitC ロボットカー

[English](README.md) | [日本語](README.ja.md)

## 概要

ESP32-DevKitC、DC モータ 2 個、TB6612FNG ドライバ、単 3 電池 4 本を使用するロボットカーの計画です。スマートフォン・PC の Web アプリまたは Bluetooth による操作を想定しています。
