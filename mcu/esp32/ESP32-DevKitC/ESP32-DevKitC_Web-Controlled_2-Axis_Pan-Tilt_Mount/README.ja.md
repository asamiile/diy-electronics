# ESP32-DevKitC Web 操作型 2 軸パン・チルト雲台

[English](README.md) | [日本語](README.ja.md)

## 概要

ESP32-DevKitC を使う Web 操作型パン・チルト雲台の計画です。SG90 サーボ 2 個、ブラケット、外部 5V/4A 電源、1000µF コンデンサを想定しています。
