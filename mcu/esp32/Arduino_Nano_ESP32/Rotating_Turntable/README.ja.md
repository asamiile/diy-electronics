# Arduino Nano ESP32 回転台

[English](README.md) | [日本語](README.ja.md)

## 概要

Arduino Nano ESP32 と TB6612FNG モータドライバで制御する回転台の計画です。10kΩ の可変抵抗で速度を設定し、タクトスイッチで回転方向を変更します。ギヤ付き DC モータは約 30〜60 RPM を想定しています。
