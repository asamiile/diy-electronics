# XIAO RP2040 LED オーディオスペクトラム

[English](README.md) | [日本語](README.ja.md)

## 概要

XIAO RP2040、Grove マイク、8×32 の WS2812B マトリクスを使用するオーディオスペクトラム表示の計画です。

### ソフトウェア開発

#### 実装状況

部品の計画と回路図ファイルを収録していますが、配線手順、ファームウェア、テスト結果は未収録です。回路図のファイル名は `ESP32-DevKitC` で始まるため、使用前に XIAO RP2040 のピン配置との一致を確認してください。外部 5V/2A 以上の電源、レベル変換器、1000µF コンデンサ、信号線の抵抗を想定しています。
